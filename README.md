# AviUtl2 Placeholder（プレースホルダー）
`プレースホルダー.obj2` はAviUtl2用カスタムオブジェクトです。

画像プレースホルダーのフレーム図形を一発で出せます。

![img](https://storage.eizo-gak.com/20260816/20260815_placeholder.gif)

　

## インストール

次のいずれかで追加します。

1. `プレースホルダー.obj2` をAviUtl2のプレビュー画面へドラッグ＆ドロップする。
2. ファイルを `XXX\ProgramData\aviutl2\Script\`、またはその直下のサブフォルダーへコピーする。
